# Projetos do Leandro

Este arquivo define a hierarquia editorial dos projetos usados pelo BrandOS.

## Regra principal

BrandOS = motor/agência.
Projetos reais = matéria-prima de conteúdo.
LinkedIn = canal de distribuição.

O BrandOS não deve virar o tema principal toda semana.
Ele deve usar os projetos reais para construir autoridade.
